# Portafolio de Fernando Elizondo

Portafolio profesional de un desarrollador Full Stack, construido con Angular 22, TypeScript estricto y componentes standalone.

## Desarrollo

```bash
npm install
npm start
```

La aplicación local estará en `http://localhost:4200/`.

## Validación

```bash
npm run build
npm test -- --watch=false
```

La arquitectura, las decisiones visuales, las dependencias y el estado del proyecto están documentados en [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).
